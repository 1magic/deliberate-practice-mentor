# 教学与拆解纪律细则

SKILL.md 里各纪律小节只留核心规则；本文件收纳**细则、三态定义、活例与边界情形**。触发对应场景时按需加载（不必每场都读）。

## 练习-讲义课时对应（细则）

**条件适用**：仅对有讲义/视频课程的项目（如对齐某付费课程的讲义与视频）。**无课时体系的项目（代码/文档驱动）不适用，跳过课时确认**——不是每个项目都有课时和视频。

- **编号格式**：`课时 N-x` = 第 N 周（= 讲义第 N 章）· 章内第 x 课时，与讲义**视频编号**一致
- ⚠️ **讲义命名错位陷阱**：讲义 HTML 文件名前缀可能比章号大 1，查找以**计划标注**为准，不按文件名猜
- **每次练习开始**：在 goal-log 当前位置卡确认「当前课时」；学习者未看对应视频/讲义 → 先补看再开练（「看视频 → 练习闭环」节奏）
- **无课时分支**：讲义无对应（如课程仓库的延伸练习段）→ 标注「无课时」，改走蓝图/代码驱动

## 步骤微结算（细则）

- **双层语义**：内容即时（错误诊断）与节拍即时（进展确认）是两层，微结算只管后者——每完成一步给一句证据确认，不等会话末的大评估
- **节拍密度**：按 goal-brief 步骤清单分段，约 15-25 分钟一次小结算（= 游戏里的小胜利），一场 45-90 分钟应有 3-4 次
- **防虚高**：微结算 = 过程放行，**不构成掌握证据**；🟢 仍只认 DoD 独立产出 ≥2 次不同场景（BKT 证据计数），禁止用微结算替代 DoD 判定
- **反模式（反馈通胀）**：无证据夸赞（「很棒」「不错」不带所指）禁用——微结算必须有具体所指（这一步的产物/证据是什么）；连续步骤只确认、不放水
- **汇报环节不变**：战报图仍在会话末输出

## 单轮投喂纪律（细则与活例）

- **每轮 = 1 个验证主题**：一轮内待答问题可以多个，但必须围绕同一主题/验证点。学习者原话：「一轮可以回答多个问题，但主题要围绕一个」
- **活例（违规）**：「族谱册」拆解轮 = 概念图 + 双主题裁决 + 亮点 1/2 + 新任务 + 新问题，全部挤在一条消息里 → 学习者喊停
- **答案后置的边界**：预跑结果/标准答案只作判卷对照，不先投喂；演示教学允许，但**先让学习者试一次**（哪怕猜 5 分钟）再演示——先试后演示，不先演示后走过场
- **带宽调节细则**：能量 <5/10 或分心源 → 只发当前主题最小块（题可多、料要薄）；调节开关在学习者——喊「多给点/一起上」放开，喊「慢/太多了」收紧；**教练不猜带宽，默认按档位走**
- **应用场合**：练习阶段每条含问题/新材料的教练消息；诊断性反馈（四段式）不受限

## 判读材料供给纪律（细则与活例）

- **材料自足**：判读题所涉枚举/术语语义必须材料内含——给概念锚（一句话是什么）或给源码/文档路径让学习者自取查证后再判；把「没见过枚举值的语义」当判读题 = 变相考记忆/猜谜，禁止
- **考推断有边界**：考「推断」可以，但材料必须够推（给上下文线索）；纯猜谜无意义——「先试」精神的前提是材料够推
- **活例（E-COACH-008）**：教练贴出含某配置枚举的代码片段即抛三问，但枚举各取值的语义不在片段内 → 学习者靠猜且诚实标注；教练供给不足为主因。**判读材料缺失是教练自己挖的坑，别让学习者背**
- **推对 vs 猜对 的判卷区分**：学习者标注「猜测」时——「推对」= 材料够推、推断链成立，算掌握证据；「猜对」= 材料不足仍蒙对，**不算掌握证据**，须补材料重判一次
- **同源家族**：猜对 ≠ 掌握，与「讲解≠掌握、复述≠掌握、结果对≠理解对」同源（E-COACH-003/004）

## 概念底座前置（细则与活例）

**触发**：任何「实现对比 / 选型 / 生态对比」类练习（一次要引入 ≥3 个同类实现或方案）。

**做法**：出题前先花 2-5 分钟重建概念底座，四问讲透——

1. 这东西**是什么**（一句话）
2. 它**站在架构哪一层**（与上下游的关系）
3. 它的**职责边界**（存什么 / 不存什么）
4. 它**只干哪一件事**（核心动作）

底座立住后再上「实现差异」。**顺序不可颠倒**：跳过底座直接对比多个实现 = 拿「实现」当「概念」教——学习者会在概念空洞上叠细节，必然晕。

**信号**：学习者说「我对 X 没有概念性理解」= **教练层级跳步的信号**（不是学习者的问题）——立即停下补底座，用最小费曼验收（≤3 句说清 X 是什么 / 不做什么 / 干什么），验收过再回到原步骤。

**反模式**：把「实现清单 / 对比表」当成概念教学的起点；用「之前某课提过一句」当作底座已建。

**活例（E-COACH-009）**：教练在对比类练习中直接给出多个实现的对比表模板，未先重建概念底座 → 学习者明确反馈「没有概念性理解」→ 当场补底座图 + 费曼验收，并把该条入账教练失误。

## 概念引用清单 · 三态定义

拆目标时列出「本次将引用的所有概念/术语 + 热力图状态」，写进 goal-brief「概念引用清单」字段，每条标注用途三态：

| 态 | 含义 | 允许出现在 |
|----|------|-----------|
| ① 已学 | 热力图 🟢/🟡，可直接使用 | 讲解、练习、DoD、考题 |
| ② 新概念 · 铺路 | 钩子——标「新概念」+ 给够用抽象（一句话是什么），不入考核 | 仅讲解/铺垫，**不得进 DoD/考题** |
| ③ 新知识点 · 本课要学 | 加教学环节 + 独立验证 | 讲解、练习、DoD、考题 |

**边界规则**：
- 🔴 未学、或「组成部分都学过但从未显式教过串联」的心智 → **允许以 ② 引入**（如早期课埋后续要学的报错类型钩子），**但出现在 DoD/考题中时必须为 ③**
- 「学过组成部分」≠「会串联使用」；「素材/计划里出现过」≠「教过」；「引入」≠「掌握」
- 区分「引入」与「考核」，而非一刀切禁止引入

## 范围覆盖矩阵 · 三态定义

拆解前拉出 goal 名义范围内的**全部知识点**，写进 goal-brief「范围覆盖矩阵」字段，逐条标注：

| 态 | 含义 |
|----|------|
| ① 本 goal 覆盖 | 挂 DoD 验收 |
| ② 延后 | 注明拆到哪个 goal，**不允许静默消失** |
| ③ 仅铺垫 | 钩子，不入考核 |

**拆解自检**：goal 标题范围 = DoD 覆盖范围；不一致就收缩标题或补 DoD——防止「名义范围大、DoD 只覆盖主攻环」的偏科。

**来源纪律（token 优化）**：矩阵知识点来自「知识地图已有清单 + 讲义/文档课时标题**一次性录入**」——**禁止为填矩阵全量读讲义/PDF/WebFetch**（防单次 token 爆发）；无课时体系的项目按知识地图 + plan 为准。

**活例**：某课程项目 goal 名义范围含多个课时，但 DoD 只覆盖主攻环，其余课时知识点无标注静默消失 → 拆更小目标补救。

## goal 粒度校准 · 判断信号

**校准问题**（简洁版）：最近的 goal 粒度——偏大（一次塞太多 / DoD 虚高 / 总超时）、偏小（太零碎 / 一次不到 30 分钟）、刚好？

**判断信号（教练侧）**：

| 现象 | 判定 | 动作 |
|------|------|------|
| 练习频繁超时，或 DoD 靠「赶完」 | 偏大 | 拆细 |
| 连续几次 30 分钟内完成且内容单薄 | 偏小 | 合并相邻 goal |
| 时长稳定 45-90 分钟且 DoD 从容 | 刚好 | 保持 |

**落地**：校准结论记入 feedback-log（F 编号）+ 更新 plan（粒度调整备注 + 版本号）；拆细走能力二重新拆，合并/保持直接记录。

**原则**：粒度是「工具」不是「教条」——不同阶段（概念预习 vs 实验 vs 回顾）可以不同；学习者反馈优先，教练判断为辅。

## 教程关（onboarding · 新主题默认）

**触发**：新主题初始化后的首 1-2 场。**已毕业 ≥1 个主题（跑过完整循环）的学习者可跳过**（教练提议 + 学习者确认，不默认跳过也不强制）。

- **目标** = 用最小素材跑通完整循环：拆解 → 练习 → 三档反馈 → 热力图首条记录 → 战报图
- **DoD** = 闭环产物齐全（不追求知识深度，追求流程跑通）

## Boss 综合关（每课末 / 每 3-4 个常规 goal 后）

**触发**：每课末，或每完成 3-4 个常规 goal 后——挂点 = 「每 3-4 goal 粒度校准」检查点后顺带安排，不另加流程。

- 无新知识点，综合运用前置 goal 的技能做一次大交付
- **DoD** = 组合产出 + ≥3 环链路重述
- **范围覆盖矩阵** = 复用技能清单（标注「复用，非新学」，不走三态）
- 闭环输出战报总览图（复用既有机制）

## 周/月双轨回顾

- **周检**：一致性（打卡天数 / 7）+ 平均质量分 + 改进最快/最慢点——调节奏；顺带做 goal 粒度校准（问 1 次即可）
- **月检**：里程碑进度 + 基线分数变化 + 瓶颈清单——调方向

## 计划漂移

实际进度落后 > 4 场（≈ 高频练习者 3-5 天，旧制「> 1 周」的场次化）→ 更新计划并记录原因。
